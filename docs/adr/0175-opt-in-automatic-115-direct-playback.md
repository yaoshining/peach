# ADR-0175：可选的 115 按路径直链播放

- 状态：已采纳
- 日期：2026-11-19
- 关系：局部修订 [ADR-0174](0174-opt-in-mapped-direct-playback.md) 中只允许逐资产人工映射、不自动匹配的范围；原有人工映射、鉴权和兼容播放计划继续适用。

## 背景

用户需要让已入库的 115 视频按需使用原文件直链，避免为每个新视频手工填写映射。媒体来源、原路径、收藏和观看记录仍由现有账本维护。事先全量遍历网盘或改写媒体记录不能替代播放时的身份检查。

## 决策

自动查询默认关闭，只在用户显式配置 115 账号、账本来源根和受信任的 QMediaSync 查询服务后启用。人工复核的逐资产映射优先；其他符合条件的视频在播放时按账本中的 Windows 路径计算相对路径，不读取挂载，也不预先扫描全库。

Peach 将相对路径和账本文件大小发送到受限查询接口。查询服务负责固定授权账号和网盘根，校验完整路径、文件类型、大小与文件标识；Peach 检查响应的文件 ID、大小和提取码。两端只接受预期的服务地址与接口。服务间专用令牌随请求头发送；接口仅供可信隔离网络或经 TLS 保护的连接使用。查询服务及其日志是信任边界：服务端不得记录令牌、提取码或签名地址，用户还须检查已有入口及代理日志。

文件提取码在进程内按来源、资产、路径、大小和配置隔离缓存，最多保留 60 秒；直链地址按播放器 User-Agent 重新解析，不在 Peach 持久化。路径和大小相同并不能证明文件内容相同：文件在相同路径被同大小内容替换时，缓存有效期内可能仍使用旧文件标识；缓存到期或直链解析失败后重新查询，仍可能将替换后的文件当作原资产播放。此机制既不对照历史文件 ID，也不做内容哈希比对，不能把匹配结果当作永久身份断言。

直链查询或解析失败时，带播放会话的请求通知播放器重新取得挂载兼容计划；无会话请求继续原挂载读取。解码或直链播放失败也使用既有播放器回退机制。挂载离线、接口不可用或客户端不支持编码时，回退不保证成功。设置关闭或删除后恢复原播放方式；账本、媒体文件与观看历史不被修改。

本决定扩大 ADR-0174 向获授权终端返回短期公网 HTTPS 直链的例外，覆盖符合上述限制的按需自动查询。它不启用其他来源、画质切换或后台全库匹配，也不改变 STRM 代理隐藏上游地址的规则。直链可能被终端持有，不能视为私密令牌已经撤销。

## 验证

隔离测试覆盖授权和来源根限制、查询接口契约、缓存、User-Agent、直链失败后的兼容播放计划，以及账本中的收藏、评分与观看记录保持不变。真实网盘、客户端网络和 NAS 部署须分别验收；隔离结果不代表生产播放已验证。
